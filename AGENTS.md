## The family goal

This repo serves the family goal in [GOALS.md](https://github.com/sethshoultes/superintelligentfamily/blob/main/GOALS.md): anyone can run any site with no dashboard. Every new issue carries one `goal:*` label naming the part it serves; an issue with none is asked which part it serves before it is built. Read GOALS.md for the six parts and what done looks like. Do not copy it here.
